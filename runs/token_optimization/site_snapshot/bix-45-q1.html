Question

What is the p-value from a Mann-Whitney U test comparing RCV scores between animal and fungal orthologs using PhyKIT's rcv function?

Accepted answer
7.6968e-54
Domain
phylogenetics

bix-45-q1 forensic finding

How the cause was identified

Earlier runs in both execution conditions repeatedly produced 1.5198e-56. Agreement across independent agents showed that this was a reproducible method difference, not a random Galaxy failure, but those runs could not identify which hidden convention caused it. Later GPT-5.6 Open-ended code runs compared PhyKIT releases on the same 241 animal and 255 fungal alignments and isolated the RCV implementation change.

PhyKIT routeRCV behaviorMann-Whitney UTwo-sided p-value
2.0.3Counts gap and ambiguous symbols, normalizes by full alignment length, and prints RCV to four decimals.61157.6968e-54accepted value
2.1.93 / 2.4.1Excludes gap and ambiguous symbols and normalizes by valid residue length.5483.51.5198e-56Galaxy wrapper result

The alignments and rank-test settings were unchanged. The task names PhyKIT's rcv function but does not pin a release, while the Galaxy wrapper installs PhyKIT 2.1.93. We therefore classify the discrepancy as a benchmark-wrapper version mismatch: the Galaxy result is valid for the installed implementation, but it does not match the version-sensitive accepted value.
