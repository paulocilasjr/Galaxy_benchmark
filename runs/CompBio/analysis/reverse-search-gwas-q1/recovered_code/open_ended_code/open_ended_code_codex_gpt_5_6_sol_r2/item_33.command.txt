leads=[('1',161530617,'CTT','C'),('6',32067917,'C','T'),('17',16939677,'G','A'),('19',49525049,'CCTGCTG','C'),('4',3445429,'C','T'),('4',102486185,'C','T'),('2',111471251,'T','C'),('13',108308037,'T','A'),('2',27508073,'T','C'),('15',43464986,'T','C'),('19',1080312,'G','C'),('14',102789124,'T','C'),('14',105657511,'C','T')]
