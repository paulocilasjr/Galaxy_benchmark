# CompBioBench agent run traces

This directory contains 2,400 completed CompBioBench run directories across
24 replicates. Its directory layout matches the BixBench collections in this
dataset: model collection, question, execution condition, and replicate.

Included models are Codex GPT-5.5, Codex GPT-5.6 Sol, Codex +
DeepSeek-v4-pro-0813, and Codex GPT-5.6 Luna. Each collection has an
`index.json` and a short package summary.
