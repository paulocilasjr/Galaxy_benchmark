## Summary

The pydeseq2 differential expression analysis was completed with the following steps:

1. **Data**: Batch-corrected read counts (723 samples × 59,453 genes) with 36k genes retained after standard low-count prefiltering (FAM138A had 292 total counts, well above the threshold)

2. **Design**: `~ batch + sex` — batch as a categorical covariate, sex as the effect of interest

3. **Contrast**: M vs F (reference = F), testing the `sex[T.M]` coefficient

4. **Shrinkage**: Default apeglm method applied via `lfc_shrink(coeff="sex[T.M]")`
