## Result

The **W chromosome** shows the highest density of age-related CpG sites in the Jackdaw genome.

### Galaxy pipeline summary

| Step | Tool | Input | Output |
|------|------|-------|--------|
| 1 | **Cut** | `JD_AgeRelated_CpG_noMT_Final.csv` → columns 10,1 | Chromosome + Pos (tabular) |
| 2 | **Group** | Cut output → group by Chromosome, Count Distinct on Pos | 37 rows: chromosome + CpG count |
| 3 | **Cut** | `JD_Chromosome_Length.csv` → columns 1,2 | Chromosome + Length (tabular) |
| 4 | **Join** | Group output ⋈ Length file on chromosome | 36 rows: chromosome, count, length |
| 5 | **Compute** | `c2/c4` → density = count / length | Density column appended |

### Top densities

| Chromosome | CpG Sites | Length (bp) | Density |

| **W** | 184 | 6,742,290 | 2.73 × 10⁻⁵ |
| 33 | 6 | 477,022 | 1.26 × 10⁻⁵ |

The W chromosome (a microchromosome at ~6.7 Mb) has nearly double the density of the next-ranked chromosome, driven by a high count of age-related CpG sites (184) on a relatively small chromosome.
