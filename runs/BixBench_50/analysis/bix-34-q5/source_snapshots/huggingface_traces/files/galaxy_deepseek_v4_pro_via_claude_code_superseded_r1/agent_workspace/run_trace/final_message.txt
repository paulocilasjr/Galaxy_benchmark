The computation is complete. Here's a summary:

**Method:**
1. Copied the seed Galaxy history
2. Identified 100 IQ-TREE phylogenies (`.treefile`) in `scogs_animals.zip` and 249 in `scogs_fungi.zip`
3. Created a Galaxy UDT using the PhyKIT BioContainer that, for each tree, computes all pairwise patristic distances via `phykit patristic_distances -v` and outputs the per-tree mean
4. Ran the UDT on both archives via Galaxy
5. Computed the median of per-tree means for each group, then the ratio
