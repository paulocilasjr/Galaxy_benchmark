The Mann-Whitney U statistic is **6350**.

Here's a summary of the analysis:

**Data**: 241 single-copy ortholog groups (SCOGs) with MAFFT protein alignments shared between the animal clade (4 species: *C. elegans*, *G. gallus*, *M. musculus*, *X. laevis*) and the fungal clade (4 species: *N. crassa*, *S. cerevisiae*, *S. pombe*, *U. maydis*).

**Method**:
1. For each SCOG, computed the percentage of parsimony informative sites (positions where ≥2 different amino acids each occur in ≥2 sequences, excluding gaps) in both the animal and fungal alignments.
2. Animals: mean PI% = 0.26% (median = 0.00%), reflecting very low sequence diversity.
3. Fungi: mean PI% = 3.41% (median = 3.56%), reflecting substantially higher diversity.
4. Mann-Whitney U test (two-sided) comparing the two distributions: U = 6350, p ≈ 0 (fungi have stochastically greater PI% than animals).
