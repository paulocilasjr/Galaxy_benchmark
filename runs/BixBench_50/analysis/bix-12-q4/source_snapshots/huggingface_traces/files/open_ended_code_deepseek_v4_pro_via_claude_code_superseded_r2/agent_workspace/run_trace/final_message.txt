Here's a summary of the analysis:

**Approach:**
- Extracted 241 shared single-copy ortholog groups (SCOGs) from both the animal (Cele, Ggal, Mmus, Xlae) and fungi (Ncra, Scer, Spom, Umay) datasets
- For each SCOG, parsed the MAFFT multiple sequence alignment and computed the percentage of parsimony informative sites (columns with ≥2 character states, each present in ≥2 sequences; gaps treated as a character state)
- Compared the two distributions of PI% (animals vs fungi) using the Mann-Whitney U test

**Key findings:**
- Animal PI%: mean 0.31%, median 0% — 219 of 241 alignments have 0% PI, largely because only 22 animal alignments contain all 4 species
- Fungi PI%: mean 4.94%, median 5.50% — 201 of 241 alignments have all 4 species
- Mann-Whitney U (animals): **5604** (p ≈ 2×10⁻⁶²)
