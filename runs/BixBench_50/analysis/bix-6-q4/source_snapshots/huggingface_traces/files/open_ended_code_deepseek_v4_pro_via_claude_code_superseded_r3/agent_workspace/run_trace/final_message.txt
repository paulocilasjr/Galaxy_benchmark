The Spearman correlation coefficient between the replicate MAGeCK P-values for chronic round 1 is **0.02097**.

The analysis used the `MAGeCK P-values` sheet from the input Excel file, extracting the two replicate columns `Chronic Round1 S1` and `Chronic Round1 S2` (23,726 genes each, no missing values). The Spearman rank correlation measures the monotonic relationship between the two sets of gene-level p-values — the very low value (~0.021) indicates almost no rank agreement between the two replicates, which is consistent with the high noise typical of individual replicate p-values in pooled CRISPR screens.
