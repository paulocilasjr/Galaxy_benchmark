## Summary

After calculating Pearson correlations between gene length and average gene expression for 19,942 protein-coding genes across four immune cell types, the results are:

| Cell Type | Samples | Pearson r |
|-----------|---------|-----------|
| **CD4**   | 151     | 0.06170   |
| **CD8**   | 145     | 0.05513   |
| **CD14**  | 132     | **0.03169** |
| **CD19**  | 137     | 0.04711   |

**CD14** has the weakest correlation (lowest absolute Pearson r = 0.0317) between gene length and mean expression levels among protein-coding genes.

The computation was performed on Galaxy (usegalaxy.org) using a custom UDT with `pandas:2.2.1` that:
1. Filtered the GeneMetaInfo dataset to 19,942 protein-coding genes
2. For each cell type, computed per-gene mean expression across all samples of that type
3. Computed the Pearson correlation between gene Length and mean expression
4. Output the results to `codex_output/answer.txt`
