## Results

The analysis was performed as follows:

1. **Data**: Loaded three DESeq2 RDS results files (WT vs mutants 97, 98, 99) for *Pseudomonas aeruginosa* PA14, each containing 5,828 genes.

2. **KEGG mapping**: Mapped gene identifiers (PA14 locus tags) to KEGG organism `pau` (*P. aeruginosa* UCBPP-PA14), yielding a universe of 2,041 genes across 116 KEGG pathways (≥5 genes each).

3. **Foreground definition**: Genes with |log₂FC| > 1.5, split by direction:
   - Strain 97: 13 up, 74 down
   - Strain 98: 12 up, 54 down
   - Strain 99: 43 up, 141 down

4. **ORA**: Hypergeometric test per pathway per direction per strain, with Benjamini-Hochberg FDR correction across all 116 pathways.

5. **Intersection**: Zero pathways were significantly enriched (FDR < 0.05) in the same direction across all three strains. Several pathways were significant in two of three strains (e.g., Phenazine biosynthesis, Quorum sensing, Nitrogen cycle), but none reached significance in all three.

**Answer: 0**
