The median percentage of parsimony informative sites across the 255 fungal gene alignments (`.faa.mafft` files in `scogs_fungi.zip`) is **5.437%**.

**Method:**
- Parsed all 255 MAFFT-aligned single-copy ortholog groups from `scogs_fungi.zip`, each containing aligned amino acid sequences from 4 fungal species (*Neurospora crassa*, *Saccharomyces cerevisiae*, *Schizosaccharomyces pombe*, *Ustilago maydis*), though some alignments have fewer taxa due to gene absence.
- A site is **parsimony informative** if at least two different character states each occur in at least two sequences (gaps treated as a character state, per the AMAS convention standard in BUSCO-based phylogenomic pipelines).
- Computed the percentage of parsimony informative sites per alignment independently, then took the median across all 255 alignments.
