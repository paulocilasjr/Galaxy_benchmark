The maximum number of parsimony informative sites in any animal gene alignment is **29**.

Here's the summary of the analysis:

1. **Data**: The `scogs_animals.zip` archive contained 241 MAFFT alignments of single-copy ortholog genes across 4 animal species (*C. elegans*, *G. gallus*, *M. musculus*, *X. laevis*).

2. **Method**: A Galaxy User-Defined Tool (UDT) was created using `quay.io/biocontainers/python:3.12.12` to process all 241 `.mafft` alignment files. For each alignment, it computed parsimony informative sites using the standard definition: a site is parsimony informative if at least 2 different character states are present, each occurring in at least 2 sequences (ignoring gaps and ambiguous characters).

3. **Results**: 
   - 22 alignments contained all 4 species and could potentially have PIS
   - 78 alignments had 3 species, 71 had 2, and 70 had 1 — all yielding 0 PIS by the strict definition
   - Maximum PIS: **29** (found in genes `570797at2759.faa` and `1428854at2759.faa`, both with all 4 species)
