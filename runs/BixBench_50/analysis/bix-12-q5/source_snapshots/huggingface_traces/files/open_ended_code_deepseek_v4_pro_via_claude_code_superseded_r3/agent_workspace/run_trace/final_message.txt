The maximum number of parsimony informative sites in any animal gene alignment is **35**.

This comes from gene `1428854at2759`, a 1021-amino-acid alignment across all four animal species (*Caenorhabditis elegans*, *Gallus gallus*, *Mus musculus*, *Xenopus laevis*). A parsimony-informative site requires at least two distinct character states that each appear in at least two sequences. Across all 23 multi-sequence alignments in the animal dataset (from `scogs_animals.zip`), the counts ranged from 3 to 35.
