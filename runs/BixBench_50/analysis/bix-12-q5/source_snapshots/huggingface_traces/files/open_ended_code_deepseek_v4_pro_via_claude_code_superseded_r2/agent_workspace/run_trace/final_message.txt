**Method:** A site is parsimony informative if it has at least two different amino acid states (excluding gaps and ambiguous characters like X/?), and each state appears in at least two sequences. Of the 241 aligned BUSCO genes in the animal single-copy ortholog set, only the 22 alignments with all 4 species (Cele, Ggal, Mmus, Xlae) can support parsimony-informative sites, since at least 4 sequences are needed for a 2-2 split pattern. Both top genes achieve 29 such sites.
