The analysis is complete. Here's a summary of what was done:

1. **Copied seed history** and its two datasets (ROSMAP gene expression matrix + metadata)
2. **Inspected data**: 2456 genes × 222 samples, values range 0 to ~4.9M with 3 zeros
3. **Converted CSV to TSV** using Galaxy's Convert tool (commas → tabs)
4. **Transposed** the matrix using Datamash Transpose to get samples as rows (223 rows incl. header) × genes as columns (2457 cols)
5. **Created a UDT** (Python + scikit-learn) that:
   - Added pseudocount 1 to all values: `data + 1.0`
   - Applied log10 transformation: `np.log10(data + 1.0)`
   - Ran PCA with 100 components via `sklearn.decomposition.PCA(n_components=100)`
   - Output explained variance ratios
6. **Extracted result**: PC1 explains **56.47%** of total variance
