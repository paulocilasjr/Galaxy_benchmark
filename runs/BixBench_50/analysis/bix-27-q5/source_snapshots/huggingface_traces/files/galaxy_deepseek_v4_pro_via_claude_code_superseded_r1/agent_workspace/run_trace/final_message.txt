## Summary

**Pipeline executed on Galaxy (usegalaxy.org):**

1. **Identity resolution**: Inspected 222 sample columns in the ROSMAP gene expression matrix, found 21 sample IDs with conflicting germline-invariant attributes (sex, APOE genotype) across repeated records. Per the expression-matrix-pca skill's pre-fit gate, excluded all 44 occurrences of these 21 collided IDs, retaining 178 resolved samples.

2. **Data preparation**: Uploaded filtered matrix (2456 genes × 178 samples) to Galaxy. Transposed via Datamash so samples become rows, genes become columns (178 × 2456).

3. **Log10 transformation**: Applied log₁₀(x + 1) with pseudocount 1 to all values.

4. **PCA**: Ran PCA via R's `prcomp` (SVD method, center only) on all 2456 gene features across 178 samples.

5. **Variance extraction**: Read the "Proportion of variance explained" from the PCA summary output.

**Result**: The first principal component explains **55.97%** of the total variance.
