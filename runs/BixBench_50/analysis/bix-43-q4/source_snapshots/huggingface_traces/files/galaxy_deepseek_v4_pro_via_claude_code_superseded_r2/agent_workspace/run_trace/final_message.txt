The overlap ratio for the **TP53 Regulates Transcription Of Cell Cycle Genes** pathway is **8/47**.

Here's a summary of the analysis:

1. **DESeq2** was run on Galaxy comparing CBD/cisplatin (Group 9) vs DMSO (Group 3), yielding 525 DEGs (padj < 0.05, |log2FC| ≥ 0.5), of which 512 mapped to gene names.

2. **GSEApy enrichment** (ORA) was run with Reactome_2022 gene sets using all 13,546 mapped genes as background. The TP53 Cell Cycle pathway (R-HSA-6791312) ranked #1 by p-value.

3. **Overlap**: 8 DEGs overlapped with the pathway (BTG2, CDKN1A, PCNA, RGCC, CCNE2, CCNE1, PLK2, BAX). The total pathway size (47 genes) was confirmed by back-calculating from the odds ratio (5.289) and verifying against the hypergeometric p-value (3.38 × 10⁻⁴).
