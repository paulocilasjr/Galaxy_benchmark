The AIC for the logistic regression model with BMI as the sole predictor of treatment response (PR) is **111.8124599252796**.

Here's a summary of the analysis:

- **Data**: 121 rows in `data.xlsx`, with 80 complete cases (41 PR, 17 SD, 22 PD) having both efficacy and BMI.
- **Outcome**: Binary — PR = 1 (treatment response), SD/PD = 0 (no response).
- **Model**: `Logit(PR ~ BMI)` with intercept, fitted via MLE using `statsmodels`.
- **Log-likelihood**: −53.906
- **Parameters (k)**: 2 (intercept + BMI coefficient)
- **AIC**: −2 × (−53.906) + 2 × 2 = **111.812**
