## Summary

The Mann-Whitney U statistic comparing raw parsimony informative site counts between animals and fungi is **6748**.

### Analysis pipeline:

1. **Inputs**: 4 animal species (Cele, Ggal, Mmus, Xlae) and 4 fungal species (Ncra, Scer, Spom, Umay) — each with single-copy orthogroup (SCOG) alignments:
   - `scogs_animals.zip`: 241 SCOG MAFFT alignments
   - `scogs_fungi.zip`: 255 SCOG MAFFT alignments

2. **Parsimony informative sites**: Computed per-alignment via a Galaxy UDT. A site is parsimony informative when ≥2 amino acid states each appear in ≥2 sequences (gaps excluded).
   - Animals: mean 1.1 PIS, range 0–29 (n=241)
   - Fungi: mean 21.8 PIS, range 0–162 (n=255)

3. **Mann-Whitney U test**: Run via Galaxy's Nonparametric rank tests tool (two-sided, asymptotic method with continuity correction, animals as group A).
   - **U = 6748**, p ≈ 1.08 × 10⁻⁵⁹
