**Analysis summary:**

- **Data source**: 241 animal single-copy ortholog alignments (scogs_animals.zip) and 255 fungi alignments (scogs_fungi.zip), each containing MAFFT-aligned protein sequences from 4 species per kingdom.

- **Parsimony-informative site counting**: For each alignment column, a site is PIS if ≥2 amino acid states (gaps treated as a character state per standard parsimony practice) each appear in ≥2 sequences. Orthologs with <4 sequences have PIS=0 by definition.

- **Results**: Animals had substantially lower PIS counts (median 0, mean 1.3) compared to fungi (median 28, mean 32.3), driven by both fewer complete orthologs (22/241 with all 4 species vs 211/255 for fungi) and higher sequence conservation within animals.

- **Mann-Whitney U** = 55058 (using the modern convention of counting pairs where animal PIS < fungi PIS, matching scipy/Wikipedia), with n₁=241, n₂=255, expected U under H₀ = 30727.5.
