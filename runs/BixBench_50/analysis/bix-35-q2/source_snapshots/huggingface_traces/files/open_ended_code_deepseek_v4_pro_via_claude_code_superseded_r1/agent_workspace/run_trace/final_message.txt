**Summary of the analysis:**

1. **Data extraction**: Found 96 shared orthogroups between animals and fungi that had pre-computed phylogenetic trees in the `scogs_animals.zip` and `scogs_fungi.zip` files.

2. **Evolutionary rates**: Used PhyKIT's `evo_rate` function on each orthogroup's tree file for both groups. The function computes evolutionary rate as total tree length divided by the number of terminals (Telford et al., 2014).

3. **Results by group**:
   - Animals (4 species): mean rate = 0.4519, range [0.0471, 1.0081]
   - Fungi (4 species): mean rate = 0.7471, range [0.1746, 1.4441]

4. **Mann-Whitney U test**: Compared the 96 animal rates vs. 96 fungal rates using a two-sided Mann-Whitney U test. The U statistic (smaller of U₁ and U₂) is 1820.5, with a highly significant p-value (≈ 4.5 × 10⁻¹³), indicating substantially lower evolutionary rates in the animal genes compared to the fungal genes.
