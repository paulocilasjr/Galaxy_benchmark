### Analysis approach

1. **Data extraction**: Read both RDS files containing DESeq2 differential expression results by unserializing the raw objects and extracting the `listData` (baseMean, log2FoldChange, lfcSE, stat, pvalue, padj) with PA14 locus tags as rownames.

2. **Condition mapping**:
   - `res_GluFevsGluFePlus.rds` → **iron-depleted condition** (glucose + Fe-depleted vs glucose + Fe-Plus)
   - `res_SuccvsGluFePlus.rds` → **innate media condition** (succinate vs glucose + Fe-Plus)

3. **Gene filtering**: Genes with |log2FoldChange| > 1.5 and adjusted p-value < 0.05:
   - Iron-depleted: **224 DEGs**
   - Innate media: **541 DEGs**

4. **KEGG pathway enrichment**: Downloaded all 137 KEGG pathways for *P. aeruginosa* PA14 (organism code `pau`) via the KEGG REST API. Performed over-representation analysis (Fisher's exact test, one-sided) with Benjamini-Hochberg FDR correction.

5. **Comparison**: 9 pathways significantly enriched (padj < 0.05) in iron-depleted; 15 in innate media. **3 pathways** are significant only in iron-depleted, not in innate media:
   - **pau01053** — Biosynthesis of siderophore group nonribosomal peptides (iron-only, expected given iron starvation)
   - **pau00460** — Cyanoamino acid metabolism
   - **pau00643** — Styrene degradation
