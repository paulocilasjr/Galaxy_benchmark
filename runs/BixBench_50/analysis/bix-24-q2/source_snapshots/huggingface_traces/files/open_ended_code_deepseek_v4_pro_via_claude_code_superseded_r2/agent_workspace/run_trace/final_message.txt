**Differential Expression (CBD_IC50 vs DMSO, padj < 0.05, |log2FC| > 0.5):**

**GO Biological Process Enrichment (FDR < 0.05):**
- **Upregulated genes**: Only 2 significant GO BP terms — both developmental (`animal gross anatomical part developmental process`, `anatomical structure development`). **Zero metabolic terms.**
- **Downregulated genes**: 59 significant GO BP terms, of which **31 are metabolic**, spanning:
  - Glycolysis (glycolytic process, canonical glycolysis, glucose catabolic process)
  - Carbohydrate metabolism (carbohydrate metabolic/biosynthetic/catabolic process)
  - Glucose/hexose/monosaccharide metabolism
  - Gluconeogenesis
  - Nucleotide catabolism (purine nucleotide catabolic process)
  - Energy metabolism (ADP, pyridine nucleotide, nicotinamide nucleotide)
  - Hypoxia response

**Conclusion**: CBD treatment in CRC cells overwhelmingly drives the **downregulation** of metabolic genes, particularly those involved in glycolysis, carbohydrate metabolism, and energy production — consistent with suppression of the Warburg effect/glycolytic phenotype characteristic of cancer cells.
