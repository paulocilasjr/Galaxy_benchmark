The coefficient estimate (change in log-odds) for age in a simple logistic regression model of camrelizumab treatment response is **-0.074954**.

Here's the summary of the analysis:

- **Data**: 80 patients from `inputs/data.xlsx` (rows with complete data)
- **Response**: Binary — PR (Partial Response) = responder (1), SD/PD = non-responder (0), following RECIST convention
- **Predictor**: Age (continuous, range 40–75 years)
- **Model**: Simple logistic regression: logit(P(response)) = β₀ + β₁ × Age
- **Result**: Age coefficient = -0.07495 (SE = 0.02435, p = 0.0021, 95% CI: [-0.1227, -0.0272])
- **Convergence**: Confirmed; results cross-verified with both statsmodels and scikit-learn

The negative coefficient indicates that older age is associated with lower odds of responding to camrelizumab treatment.
