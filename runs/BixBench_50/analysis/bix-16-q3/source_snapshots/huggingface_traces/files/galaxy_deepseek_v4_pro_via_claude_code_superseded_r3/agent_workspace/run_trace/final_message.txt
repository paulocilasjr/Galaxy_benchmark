## Summary

**Answer: 3 genes** show strong positive Spearman correlation (ρ ≥ 0.6) between expression and essentiality across cell lines.

### Analysis performed on Galaxy (usegalaxy.org):

1. **Data**: 
   - `CRISPRGeneEffect.csv` — 1,178 cell lines × 17,917 genes (DepMap gene effect scores)
   - `OmicsExpressionProteinCodingGenesTPMLogp1BatchCorrected.csv` — 1,673 cell lines × 19,139 genes

2. **Method**: Used the **Feature-wise Correlation Tests** tool (Statistics panel) with Spearman rank correlation. CRISPR scores were negated (multiplied by −1) to convert dependency scores to "essentiality" where higher values indicate greater essentiality. This ensures a *positive* correlation means higher expression → higher essentiality.

3. **Results**: 
   - 1,103 cell lines and 17,676 genes were successfully matched
   - **3 genes** had Spearman ρ ≥ 0.6:

   | Gene | Spearman ρ |
   |------|-----------|
   | CCND1 (595) | 0.629 |
   | FERMT2 (10979) | 0.612 |
   | KLF5 (688) | 0.602 |
