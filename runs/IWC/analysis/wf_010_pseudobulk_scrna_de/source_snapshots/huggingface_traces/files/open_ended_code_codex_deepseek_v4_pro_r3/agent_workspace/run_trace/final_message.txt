Gene filtering used N=34, median sample total M=556,360, S=27, and the specified CPM threshold, retaining 1,429 genes. Differential expression used DESeq2 with `~ disease + cell_type`, reference level `COVID-19`, and the `normal vs COVID-19` contrast, so positive log2 fold changes indicate higher expression in normal.
