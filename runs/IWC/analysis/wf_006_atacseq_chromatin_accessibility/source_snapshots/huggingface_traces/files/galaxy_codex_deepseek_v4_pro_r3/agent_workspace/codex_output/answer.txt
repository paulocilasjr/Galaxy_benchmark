Pipeline summary:

- Created a paired collection from the provided fastq inputs.
- Trimmed and filtered reads with fastp using Nextera adapters, paired-end adapter detection, Q20 threshold, 70% unqualified limit, and minimum post-trim length 15.
- Aligned with Bowtie2 to hg19.
- Retained proper-pair, MAPQ ≥ 30, non-mitochondrial reads with Samtools.
- Removed PCR duplicates with Picard MarkDuplicates.
- Called peaks with MACS2 using `BAMPE`, no control, and q-value cutoff 0.05.
