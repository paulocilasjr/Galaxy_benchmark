Pipeline summary:

- Nextera adapters were removed by paired-end overlap detection with fastp.
- Bases below Phred 20 were treated as low quality; pairs were removed if either mate had >70% low-quality bases or was <15 bp after trimming.
- Surviving pairs were aligned to hg19 with Bowtie2.
- Alignments were filtered to proper paired-end alignments with MAPQ ≥ 30, excluding chrM.
- PCR duplicates were removed with `samtools markdup -r`.
- Peaks were called with MACS2 using `BAMPE`, q-value 0.05, and no control.
