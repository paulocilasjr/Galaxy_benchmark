# bix-11-q1 retrospective execution-history audit

Start with the [scientific report](history_analysis.md). Its previous exact version is [preserved](history_analysis.v1.md). The machine-readable companion is [history_analysis_evidence.json](history_analysis_evidence.json), validated against [Schema 2.0](history_analysis_evidence.schema.json) by [validate_audit.py](validate_audit.py).

The package covers the 12 Galaxy and 12 open-ended-code runs supplied by the user. Supporting records include the [allowed-task reference](bix-11-q1.json), [run inventory](run_manifest.json), [input provenance](input_manifest.json), [Galaxy source snapshots](source_snapshots/galaxy/retrieval_manifest.json), [Galaxy trace manifest](source_snapshots/huggingface_traces/manifest_galaxy.json), [code trace manifest](source_snapshots/huggingface_traces/manifest.json), [selected Galaxy outputs](selected_outputs/galaxy/manifest.json), [recovered-code manifest](recovered_code/manifest.json), and per-run [Galaxy](job_ledgers/galaxy) and [code](job_ledgers/open_ended_code) ledgers.

All 24 original trace packages, including fixed answers, original evaluator records, usage, and event logs, were retrieved. The 12 Galaxy labels map to 11 public history IDs; ten provided detailed public contents and jobs, while Luna replicate 2's 8,801-dataset history did not return contents. This audit ran no new benchmark jobs, executed no recovered code, and did not open hidden ground truth. Trace copies are redacted derivatives with original and retained hashes recorded in their manifests. No commit or push is part of this audit.
