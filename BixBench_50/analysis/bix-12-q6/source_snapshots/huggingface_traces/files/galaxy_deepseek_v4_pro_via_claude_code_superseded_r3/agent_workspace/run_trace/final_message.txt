The Mann-Whitney U statistic is **6748**.

**Summary of the analysis:**

1. **Data**: `scogs_animals.zip` (241 MAFFT alignments) and `scogs_fungi.zip` (255 MAFFT alignments) from the seed history, each containing single-copy ortholog alignments.

2. **Per-alignment metric**: Used a custom Galaxy UDT with the `biocontainers/phykit:2.3.0` container to run `phykit parsimony_informative_sites` on each `.mafft` alignment, producing tabular outputs with parsimony informative site counts per ortholog.

3. **Group comparison**: Used the Galaxy "Nonparametric rank tests" tool (`mann_whitney_u`, two-sided, auto method with continuity correction) comparing the parsimony informative site counts between animals (n=241) and fungi (n=255).

4. **Result**: U = 6748, p ≈ 1.08×10⁻⁵⁹ — animals have significantly fewer parsimony informative sites than fungi across these single-copy ortholog alignments.
