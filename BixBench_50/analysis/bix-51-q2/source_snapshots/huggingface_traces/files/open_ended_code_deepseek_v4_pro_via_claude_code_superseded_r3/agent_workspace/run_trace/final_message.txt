The AIC for the logistic regression model using BMI as the sole predictor of treatment response (efficacy PR) is **111.8124599252796**.

**What was done:**

1. **Data**: The `data.xlsx` file contains 121 rows with columns including Efficacy (PR, SD, PD), BMI, and Groups. BMI values are present for 80 patients (41 in Group 1, 39 in Group 2).

2. **Outcome definition**: "Treatment response (efficacy PR)" was interpreted as a binary outcome — PR (Partial Response) = 1, non-PR (SD/PD) = 0. Notably, all Group 1 patients have PR and all Group 2 patients have non-PR, meaning the only feasible analysis scope is all 80 patients with complete BMI data.

3. **Model**: Logistic regression with BMI as the sole predictor (plus intercept). Fitted via MLE using statsmodels, verified with independent scipy optimization.

4. **Result**: AIC = 111.8124599252796 (computed as 2k − 2·logL with k = 2 parameters, log-likelihood = −53.9062299626398).
