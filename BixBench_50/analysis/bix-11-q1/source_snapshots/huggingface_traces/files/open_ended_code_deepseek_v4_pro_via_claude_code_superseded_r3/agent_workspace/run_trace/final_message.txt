## Summary

**Treeness** in phylogenetics is defined as the proportion of total tree branch length that lies on internal (non-terminal) branches: **treeness = Σ internal branch lengths / Σ all branch lengths**. It measures phylogenetic signal-to-noise ratio — higher values indicate stronger, more tree-like signal.

### Computation

I extracted treeness from IQ-TREE's own output (each `.iqtree` file reports "Sum of internal branch lengths: X (Y% of tree length)"), and cross-validated by parsing the Newick `.treefile` files using dendropy. Both methods agree.

### Results

| Kingdom | Trees | 3-leaf trees | 4-leaf trees | Median treeness |
|---------|-------|-------------|-------------|----------------|
| Animals | 100   | 78 (78%)    | 22 (22%)    | **0.000000** |
| Fungi   | 249   | 38 (15%)    | 211 (85%)   | **0.050140** |

**Difference (fungi − animals): 0.05014**

The animal median is zero because 78% of animal SCOG trees have only 3 leaves (one of the four animal species is missing that ortholog), and a 3-leaf unrooted tree has no internal branches by definition. The fungi dataset is more complete, with 85% of trees having all 4 species, yielding a higher median treeness.
