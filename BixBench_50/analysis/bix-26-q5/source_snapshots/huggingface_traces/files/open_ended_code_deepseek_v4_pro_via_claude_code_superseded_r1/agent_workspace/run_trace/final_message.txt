## Summary

The analysis identified **2 KEGG pathways** that are significantly enriched under iron-depleted conditions but show no significant enrichment under innate media conditions.

### Methodology

1. **Data extraction**: DESeq2 results were read from the RDS files via R's `readRDS()`, accessing the S4 object's `listData` attributes to bypass DESeq2 package loading requirements.

2. **Gene filtering**: Genes with |log₂FoldChange| > 1.5 and adjusted p-value < 0.05:
   - Iron-depleted (GluFe vs GluFePlus): **224 DE genes** (98 with KEGG annotation)
   - Innate media (Succ vs GluFePlus): **541 DE genes** (252 with KEGG annotation)

3. **KEGG pathway mapping**: PA14 locus tags mapped to KEGG `pau` (P. aeruginosa UCBPP-PA14) via the KEGG REST API. Universe = 2,041 genes with KEGG pathway annotations.

4. **ORA**: One-sided Fisher's exact test with Benjamini-Hochberg FDR correction across 124 pathways (≥3 genes in universe).

### Iron-only pathways

| Pathway | Iron padj | Innate status |
|---|---|---|
| Biosynthesis of siderophore group nonribosomal peptides | 1.93×10⁻⁵ | 0 DE genes (not enriched) |
| Biosynthesis of secondary metabolites | 8.09×10⁻³ | padj = 8.74×10⁻² (not significant) |

The siderophore pathway is the most biologically compelling result — 6 of its 9 genes are differentially expressed under iron depletion, consistent with the known iron-starvation response in *P. aeruginosa* involving pyoverdine/pyochelin biosynthesis.
