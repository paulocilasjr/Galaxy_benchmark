## Summary

The mean of per-chromosome densities (CpGs per base pair) for filtered (>90% or <10% methylation) unique age-related CpGs in the Jackdaw genome is **1.128256802311812e-07**.

### Galaxy workflow steps:

1. **Filter CpG by Methylation** (custom UDT): Filtered `JD_AgeRelated_CpG_noMT_Final.csv` to keep only rows where `MethylationPercentage > 90 OR < 10`. Result: 52 rows across 51 unique CpG positions.

2. **Group by Chromosome** (Group tool): Counted distinct CpG positions per chromosome. 20 chromosomes have at least one filtered CpG.

3. **Select** (Grep): Removed the spurious header row from the Group output.

4. **Join** (Join two Datasets): Joined per-chromosome CpG counts with `JD_Chromosome_Length.csv` on chromosome identifier.

5. **Compute** (Compute tool): Calculated density = CpG count / chromosome length for each chromosome.

6. **Mean**: Computed the arithmetic mean of the 20 per-chromosome densities locally from the Galaxy output.
