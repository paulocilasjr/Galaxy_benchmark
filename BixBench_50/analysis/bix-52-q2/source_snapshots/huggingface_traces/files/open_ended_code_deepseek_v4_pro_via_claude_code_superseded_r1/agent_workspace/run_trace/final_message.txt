The mean of per-chromosome densities (CpGs per base pair) for filtered (>90% or <10% methylation) unique age-related CpGs in the Jackdaw genome is **1.1282568023118119e-07**.

**Approach:**
- **Filtering**: Rows where `MethylationPercentage > 90` or `MethylationPercentage < 10` — 51 unique CpG positions met this criterion (out of 1,304 total unique age-related CpGs across 24,527 rows).
- **Grouping**: Assigned each unique CpG to its chromosome via the `Pos` column (format `chr_position`).
- **Density**: Count per chromosome ÷ chromosome length in bp (from `JD_Chromosome_Length.csv`).
- **Mean**: Averaged across the 20 chromosomes that had at least one filtered CpG (chromosomes 1–6, 8, 9, 12–14, 17, 19, 21, 24, 26, 29, 30, W, Z). MT was already excluded by the input file (`noMT`), and chromosomes 7, 10, 11, 15, 16, 18, 20, 22, 23, 25, 27, 28, 31–41 had no filtered CpGs.
