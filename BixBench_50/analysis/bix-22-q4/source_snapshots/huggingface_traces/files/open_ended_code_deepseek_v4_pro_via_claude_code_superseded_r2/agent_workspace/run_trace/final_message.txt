The Pearson correlation coefficient between gene length and mean expression (across samples) for expressed protein-coding genes (total counts ≥ 10) in CD14 immune cells is:

**0.01581583020587259**

The computation used:
- **132 CD14 samples** matched between annotations and expression matrix
- **16,096 expressed protein-coding genes** (out of 19,942 total protein-coding genes) meeting the total counts ≥ 10 threshold
- Raw Pearson correlation between gene length (from `GeneMetaInfo_Zenodo.csv`) and arithmetic mean of batch-corrected read counts across CD14 samples

The near-zero correlation indicates essentially no linear relationship between gene length and expression level in this dataset, which is expected since the batch-corrected read counts already normalize for gene-length biases inherent to RNA-seq.
