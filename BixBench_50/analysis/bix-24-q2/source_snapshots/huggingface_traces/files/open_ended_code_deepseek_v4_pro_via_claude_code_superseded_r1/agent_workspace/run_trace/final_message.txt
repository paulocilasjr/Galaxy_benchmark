## Conclusion

**Downregulation** primarily drives the metabolic effects. CBD treatment suppresses core central carbon metabolism (glycolysis, pyruvate metabolism, carbohydrate catabolism) with highly significant enrichment, while upregulated metabolic terms are peripheral and borderline significant. This pattern is consistent with CBD inhibiting the glycolytic metabolism that CRC cells depend on.
