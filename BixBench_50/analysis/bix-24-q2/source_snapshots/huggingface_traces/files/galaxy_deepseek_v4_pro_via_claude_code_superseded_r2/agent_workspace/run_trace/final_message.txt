## Summary

**Answer: downregulation**

### Analysis pipeline performed on Galaxy (usegalaxy.org):

1. **DESeq2** (via UDT): CBD_IC50 vs DMSO comparison in CRC cells
   - 63,677 genes tested
   - 181 significant DE genes (padj < 0.05, |log2FC| > 0.5)

2. **gProfiler GOSt**: GO Biological Process enrichment on up/down gene sets

### Key findings:

| Metric | Upregulated | Downregulated |
|--------|------------|---------------|
| DE genes | 59 (32.6%) | **122 (67.4%)** |
| GO:BP terms enriched | 7 | **29** |
| Metabolism-related GO:BP terms | 0 core metabolism | **21 (72%)** |

**Downregulated** genes show overwhelming enrichment for metabolic processes:
- Carbohydrate, glucose, hexose, monosaccharide, and pyruvate metabolism
- Glycolytic process, gluconeogenesis, Cori cycle
- HIF-1 signaling pathway, response to hypoxia
- Nucleotide/ribonucleotide catabolic processes
- Cholesterol and sterol transport regulation

**Upregulated** genes are enriched for developmental/signaling terms (tissue development, TGF-β/SMAD, activin receptor signaling) with no core metabolic pathway enrichment.

CBD treatment in CRC cells primarily exerts its metabolic effects through **transcriptional downregulation**, suppressing glycolysis, carbohydrate metabolism, and HIF-1-driven metabolic programs.
