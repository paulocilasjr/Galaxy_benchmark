## Summary

**Question:** In the BLM mutation carrier cohort, what fraction of coding variants with VAF < 0.3 are annotated as synonymous?

**Analysis steps:**

1. **Identified BLM carriers** from `230215_Trio_Status.xlsx`: 20 samples with `BLM Mutation Status = "Carrier"`, of which 19 had corresponding variant files in the `CHIP_DP10_GQ20_PASS` directory (carrier 533 had no file).

2. **Defined coding variants** using standard Sequence Ontology terms: `synonymous_variant`, `missense_variant`, `stop_gained`, `stop_lost`, `start_lost`, `frameshift_variant`, `inframe_insertion`, `inframe_deletion`, `coding_sequence_variant`, `protein_altering_variant`. Excluded intronic, UTR, splice-region, and upstream/downstream variants.

3. **Filtered for VAF < 0.3**: Only variants with a non-null VAF strictly below 0.3 were considered. VAF=0.0 variants (all reference calls, all non-coding) had no effect on the result. Two variants with VAF exactly 0.3 were correctly excluded.

**Result across 19 carrier files:**

| Category | Count |
|---|---|
| Coding variants with VAF < 0.3 | 41 |
| Synonymous variants among those | 30 |
| **Fraction synonymous** | **30/41 ≈ 0.7317** |
