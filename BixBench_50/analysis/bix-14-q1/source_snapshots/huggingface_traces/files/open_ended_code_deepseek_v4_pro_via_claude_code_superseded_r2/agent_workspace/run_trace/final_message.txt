## Summary

**Cohort**: 20 BLM mutation carriers identified from `230215_Trio_Status.xlsx`. 19 have variant data files (carrier 533 missing).

**Method**: For each carrier, loaded their CHIP gene panel exome variant file. Extracted non-Reference variants with VAF < 0.3 and classified them as coding (`synonymous_variant`, `missense_variant`, `frameshift_variant`, `inframe_insertion`, `inframe_deletion`, `stop_gained`, `stop_lost`, `start_lost`, etc.) or non-coding (`intron_variant`, `3_prime_UTR_variant`, `5_prime_UTR_variant`, `splice_region_variant`).

**Result**: Across all 19 BLM carriers, there are **41 coding variants with VAF < 0.3**, of which **30 are annotated as synonymous_variant** (11 are missense_variant).
