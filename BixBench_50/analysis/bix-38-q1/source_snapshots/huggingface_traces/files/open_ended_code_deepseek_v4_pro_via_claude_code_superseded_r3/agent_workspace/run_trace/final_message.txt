## Summary

I computed the tree lengths for all single-copy ortholog trees using PhyKIT's `total_tree_length` command:

| Group | Trees (n) | Median tree length | 25th percentile | 75th percentile |
|-------|-----------|-------------------|-----------------|-----------------|
| Animals | 100 | 1.4219 | 0.9293 | 1.9218 |
| Fungi | 249 | 3.0962 | 2.3928 | 3.8112 |

**Fold-change (fungi / animals): 2.177508966875308**

The analysis used:
- **Animals**: 100 SCOG tree files from `scogs_animals.zip` (4 taxa: *C. elegans*, *G. gallus*, *M. musculus*, *X. laevis*)
- **Fungi**: 249 SCOG tree files from `scogs_fungi.zip` (4 taxa: *N. crassa*, *S. cerevisiae*, *S. pombe*, *U. maydis*)
- **Method**: PhyKIT `total_tree_length` (v2.3.0) computed the sum of all branch lengths for each Newick tree
- **Aggregation**: Median tree length per group, then ratio of medians (fungi/animals)
