Here's a summary of the analysis:

**Data**: Pre-computed single-copy orthogroup trees from BUSCO genes (eukaryota_odb10), with branch lengths inferred via IQ-TREE on MAFFT+ClipKIT-trimmed alignments.

**Method**: PhyKIT's `total_tree_length` (sum of all branch lengths) was computed for each tree.

| Group | Trees | Median tree length |
|-------|-------|-------------------|
| Animals (*Cele*, *Ggal*, *Mmus*, *Xlae*) | 100 | 1.4219 |
| Fungi (*Ncra*, *Scer*, *Spom*, *Umay*) | 249 | 3.0962 |

**Fold-change (fungi / animals)**: **2.177509**

The fungal ortholog trees have a ~2.18× greater median total branch length than the animal ortholog trees, consistent with the longer evolutionary distances expected among the more divergent fungal species in this dataset.
