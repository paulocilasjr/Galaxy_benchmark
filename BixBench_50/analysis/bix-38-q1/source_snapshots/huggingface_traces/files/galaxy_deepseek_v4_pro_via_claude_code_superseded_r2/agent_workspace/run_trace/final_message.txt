Here's a summary of what was done:

**Data:** The seed history contained `scogs_animals.zip` (100 IQ-TREE `.treefile` files) and `scogs_fungi.zip` (249 IQ-TREE `.treefile` files) — pre-computed phylogenetic trees from single-copy ortholog groups for 4 animal and 4 fungal species.

**Galaxy computation:** Ran **PhyKIT metrics** (v0.2.0) with "Total tree length" on both archives via the "Grouped ZIP archives" input mode on usegalaxy.org. PhyKIT computed the sum of all branch lengths for each tree.

**Results:**
- **Animals** (100 trees): median tree length = **1.4219**
- **Fungi** (249 trees): median tree length = **3.0962**
- **Fold-change** (fungi / animals) = **2.1775**

The answer was verified by manually summing branch lengths from a sample Newick tree — the PhyKIT-computed value matched exactly.
