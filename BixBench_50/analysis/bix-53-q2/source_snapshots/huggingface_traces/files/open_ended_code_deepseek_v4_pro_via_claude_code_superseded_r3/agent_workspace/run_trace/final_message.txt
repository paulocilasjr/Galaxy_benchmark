**Scientific interpretation:** Removing the batch-affected third replicates (KL3, WL3) reduces within-group variability that was inflated by batch effects. Even though the analysis now has fewer replicates (n=2 vs n=3 per condition), the remaining samples are more homogeneous, leading to more precise dispersion estimates and greater statistical power to detect differential expression. This phenomenon — where removing noisy samples increases DEG yield — is well-documented in RNA-seq studies where batch effects contribute substantial unwanted variance.
