The answer is **34.51%** — 88 out of 255 fungal genes have treeness (internal branch length proportion) above 0.06.

**Summary of the analysis:**

- **Treeness** is standardly defined in phylogenetics as the proportion of total tree length contributed by internal branches: `treeness = sum(internal branch lengths) / sum(all branch lengths)`. IQ-TREE reports this directly as "Sum of internal branch lengths: X (Y% of tree length)" in its `.iqtree` report files.

- Extracted treeness values from all 249 IQ-TREE reports in `scogs_fungi.zip`. The values ranged from 0.0000 (star trees with no internal resolution) to 0.5495.

- **6 genes** failed tree-building entirely (fewer than 3 sequences after ClipKIT trimming) and have no treeness values.

- **88 genes** had treeness > 0.06. The remaining 161 genes (including the 6 failed ones) had treeness ≤ 0.06 or undefined.

- **88 / 255 = 34.51%** of all fungal single-copy orthologs have treeness values above 0.06.
