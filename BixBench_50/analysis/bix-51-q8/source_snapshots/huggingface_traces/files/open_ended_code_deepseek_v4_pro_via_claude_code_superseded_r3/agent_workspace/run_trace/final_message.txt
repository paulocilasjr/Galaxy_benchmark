The analysis is complete. Here's a summary:

**Data**: 80 patients with complete Age and Efficacy data from the 121-row Excel file.

**Outcome**: Binary response to camrelizumab — PR (Partial Response) = 1, SD/PD (Stable/Progressive Disease) = 0 (41 responders, 39 non-responders).

**Model**: Simple logistic regression: logit(P(response)) = β₀ + β₁ × Age

**Result**: The coefficient estimate for Age (change in log-odds per one-year increase) is **-0.07495** (p = 0.0021, 95% CI: [-0.123, -0.027]). Each additional year of age is associated with approximately 7.5% lower odds of responding to camrelizumab (OR = 0.928).
