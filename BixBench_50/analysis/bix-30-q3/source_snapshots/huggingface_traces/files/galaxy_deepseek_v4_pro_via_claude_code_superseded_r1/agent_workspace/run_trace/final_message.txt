## Summary

The analysis was completed entirely on Galaxy (usegalaxy.org). Here's what was done:

1. **Copied** the seed history containing the miRNA Ct value dataset from a PLOS ONE study (pone.0150501)
2. **Converted** the Excel file to TSV and uploaded to Galaxy
3. **Created a Galaxy UDT** using the `r-base:4.3.3` BioContainer that:
   - Parsed the 175 miRNAs × 20 samples (10 patients, 10 controls)
   - Ran Welch's t-tests for each miRNA comparing patient vs. control Ct values
   - Applied **Bonferroni** correction (p × 175)
   - Applied **Benjamini-Yekutieli** correction via R's `p.adjust(method="BY")`
   - Counted significant miRNAs at p ≤ 0.05 under each correction

**Results:**
- 175 miRNAs tested, all with valid p-values
- Smallest raw p-value: hsa-miR-20b (p ≈ 4.71 × 10⁻⁴)
- Bonferroni-adjusted: 0.082 — not significant
- BY-adjusted: 0.202 — not significant
- **0 miRNAs significant under either correction**

Answer: **0:0**
