The Mann-Whitney U statistic is **6160**. Here's a summary of the analysis:

**Data**: 241 animal single-copy ortholog alignments and 255 fungal single-copy ortholog alignments from the seed history.

**Method**:
1. Created a Galaxy UDT to compute parsimony informative site (PI) percentage for each alignment in batch. A site is PI when ≥2 different character states each appear ≥2 times.
2. Validated the UDT against PhyKit's own `parsimony_informative_sites` function — both returned 2.6316% for a test alignment.
3. Ran the UDT on `scogs_animals.zip` (241 alignments) and `scogs_fungi.zip` (255 alignments).
4. Combined results and ran the Galaxy **Nonparametric rank tests** tool (Mann-Whitney U, two-sided).

**Results**:
| Group | N | Median PI% |
|-------|---|-----------|
| Animals | 241 | 0.00% |
| Fungi | 255 | 5.44% |

- **U statistic**: 6160
- **p-value**: 1.47×10⁻⁶²
