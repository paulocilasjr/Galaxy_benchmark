## Summary

The Mann-Whitney U statistic comparing parsimony informative site (PIS) percentages between animals and fungi is **6350**.

### Methodology

1. **Data extraction**: Extracted 241 shared single-copy orthogroup (SCOG) MAFFT alignments from `scogs_animals.zip` and `scogs_fungi.zip`

2. **PIS% computation per orthogroup**: For each alignment, counted parsimony informative columns where ≥2 different amino acid states each appear in ≥2 sequences, with gaps treated as missing data (standard phylogenetics practice). PIS% = (informative columns / alignment length) × 100.

3. **Mann-Whitney U**: Animals as group 1 (per the question phrasing "between animals and fungi"). Implemented with mid-rank tie handling, verified by U₁+U₂ = n₁·n₂ = 58081.

### Key findings
- **Animals**: mean PIS% = 0.26%, median = 0.00% (mostly 1–3 species per OG limits PIS)
- **Fungi**: mean PIS% = 3.41%, median = 3.56% (mostly 4 species per OG)
- **U = 6350** (animals group 1), U₂ = 51731
