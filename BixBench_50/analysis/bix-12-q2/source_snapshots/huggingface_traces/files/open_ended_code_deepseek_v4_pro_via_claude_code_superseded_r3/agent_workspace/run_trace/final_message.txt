The median percentage of parsimony informative sites across the 255 fungal gene alignments is **3.54%**.

**Method:** I extracted the 255 MAFFT-aligned single-copy ortholog alignments from `scogs_fungi.zip` (spanning *Neurospora crassa*, *Saccharomyces cerevisiae*, *Schizosaccharomyces pombe*, and *Ustilago maydis*). For each alignment, a column was counted as parsimony-informative if it contained at least two different amino acid states, each present in at least two sequences (gaps treated as missing data). The percentage of parsimony-informative sites was computed per alignment, and the median across all 255 alignments was taken.

**Summary statistics:**
- Median: 3.54%
- IQR: 2.14% – 4.64%
- Range: 0.00% – 16.50%
- 44 alignments (17%) had zero parsimony-informative sites
