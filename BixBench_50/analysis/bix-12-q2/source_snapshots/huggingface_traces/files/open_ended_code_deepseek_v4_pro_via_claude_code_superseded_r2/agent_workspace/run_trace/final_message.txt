2. **Parsimony informative site definition**: A column is PIS if it contains at least 2 distinct amino acid characters (gaps treated as a character state), each present in at least 2 sequences.

3. **Per-alignment computation**: For each of the 255 alignments, computed `PIS% = (PIS count / alignment length) × 100`.
