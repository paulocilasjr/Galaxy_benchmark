## Summary

I performed KEGG over-representation analysis (ORA) on DESeq2 results for three mutant strains (97, 98, 99) vs wildtype in *Pseudomonas aeruginosa* UCBPP-PA14 (KEGG organism code `pau`).

**Methodology:**

1. **Data extraction**: Read RDS files (DESeqResults S4 objects) by accessing the `listData` attribute, extracting log2FoldChange, pvalue, and padj for 5,828 genes per comparison.

2. **Gene set definition**: Identified differentially expressed genes with |log2FoldChange| > 1.5. All such genes also had padj < 0.05.

3. **KEGG mapping**: Retrieved 137 KEGG pathways and 2,048 pathway-annotated genes for `pau` via the KEGG REST API. Gene IDs (PA14_XXXXX) matched directly.

4. **Universe**: 2,041 genes — the intersection of tested genes and KEGG-annotated genes.

5. **ORA**: Hypergeometric test (Fisher's exact) for each pathway × direction (up/down) per strain, testing whether DE genes are over-represented in each pathway. Benjamini-Hochberg correction applied across all tests within each strain.

6. **Consistency check**: Pathways required to have padj < 0.05 in the **same direction** across all three strains.

**Result**: 0 pathways were significantly enriched (padj < 0.05) in the same direction across all three strains. Three pathways (pau01110, pau01310, pau04146) were nominally significant (p < 0.05) in the down direction in all three strains, but none survived FDR correction in strain 99 (padj = 0.053–0.079).
