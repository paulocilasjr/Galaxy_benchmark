The analysis is complete. Here's a summary of the methodology:

**Approach:**
1. Identified **19 BUSCO genes** (eukaryota_odb10) that are complete single-copy across all 8 species (4 animals: *C. elegans*, *G. gallus*, *M. musculus*, *X. laevis*; 4 fungi: *N. crassa*, *S. cerevisiae*, *S. pombe*, *U. maydis*)
2. Used pre-computed single-copy ortholog sequences and IQ-TREE phylogenies from the SCOS pipeline (MAFFT alignment + ClipKIT trimming + IQ-TREE with ModelFinder)
3. For each gene, computed **PhyKIT `evo_rate`** on the animal-only and fungi-only IQ-TREE trees separately (evo_rate = total tree length / number of terminals)
4. Compared the 19 animal rates vs. 19 fungal rates using **Mann-Whitney U test**

**Results:**
- Mean animal evo_rate: **0.489**
- Mean fungal evo_rate: **0.748**
- Mann-Whitney U statistic: **83.0** (p = 0.0046, two-sided)

Fungal genes show significantly higher evolutionary rates than animal genes across the shared ortholog set.
