## Summary

**Approach:**
1. Copied the seed history to a working history on usegalaxy.org
2. Identified 96 single-copy orthologs with pre-computed phylogenetic trees in both the `scogs_animals.zip` and `scogs_fungi.zip` archives
3. Ran PhyKIT metrics' `evolutionary_rate` function on each archive (zip mode, filtering `.treefile` suffix) to compute evo_rate = total tree length / number of terminals for each gene
4. Extracted evo_rate values for the 96 common orthologs across both kingdoms
5. Computed the Mann-Whitney U statistic comparing animal vs. fungi evolutionary rate distributions

**Results:**
| Group | n | Mean evo_rate | Median evo_rate |
|-------|---|---------------|-----------------|
| Animals | 96 | 0.452 | 0.427 |
| Fungi | 96 | 0.747 | 0.717 |

- **Mann-Whitney U** (animals): 1820.5
- Rank sum (animals): 6476.5
- Fungi show significantly higher evolutionary rates across the shared single-copy orthologs.
