The maximum number of parsimony informative sites in any animal gene alignment is **29**.

I computed this across the 241 `.mafft` animal gene alignments in `scogs_animals.zip` using the standard definition: a site is parsimony-informative when at least two non-gap amino acid characters each occur in at least two taxa. The result was cross-checked with PhyKIT’s `parsimony_informative_sites` command.
