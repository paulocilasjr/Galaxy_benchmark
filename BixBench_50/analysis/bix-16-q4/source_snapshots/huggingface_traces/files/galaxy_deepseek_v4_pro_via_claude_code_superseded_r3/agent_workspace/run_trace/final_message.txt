## Summary

Using the Galaxy "Feature-wise Correlation Tests" tool on usegalaxy.org:

**Method**: Spearman rank correlation (two-sided) with Benjamini-Hochberg multi-test correction at α = 0.05.

**Data transformation**: CRISPR gene effect scores (Chronos, negative-going) were negated to produce a positive-going essentiality score per the crispr-dependency-correlation convention.

**Results**:
- **1,103 matched cell lines** (observations present in both matrices)
- **17,676 matched genes** tested
- **3,854 genes** have a statistically significant Spearman correlation between expression and essentiality after BH correction
- **Answer: 21.803575469563249%**

The analysis detected correlations in both directions (e.g., A4GNT with positive ρ ≈ 0.091, AAGAB with negative ρ ≈ −0.113), consistent with the "in either direction" specification.
