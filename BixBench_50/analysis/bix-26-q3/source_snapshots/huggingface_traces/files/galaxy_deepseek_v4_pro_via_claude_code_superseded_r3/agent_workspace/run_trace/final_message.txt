## Summary

The analysis was completed on Galaxy (usegalaxy.org). Here's what was done:

1. **Differential expression filtering**: From the `res_GluFevsGluFePlus.rds` DESeq2 results (Glucose FeMinus vs FePlus in *Pseudomonas aeruginosa* PA14), I extracted significantly upregulated genes with **log2FC > 1.5** and **adjusted p-value < 0.05** → **133 genes**.

2. **KEGG pathway mapping**: Built a gene-to-pathway mapping table from the KEGG REST API for *P. aeruginosa* PA14 (organism code `pau`), containing 5,785 gene-pathway associations across 137 pathways covering 2,048 unique genes.

3. **KEGG ORA enrichment**: Ran over-representation analysis on Galaxy using the KEGG ORA tool with:
   - Foreground: 133 upregulated genes (40 mapped to KEGG)
   - Universe: all 2,048 mapped genes
   - BH adjustment across all 137 pathways

4. **ABC transporters (pau02010)**: 11 genes from the upregulated set contribute to this term.

The 11 genes are: PA14_10160, PA14_10180, PA14_20030, PA14_33540, PA14_33550, PA14_33560, PA14_33690, PA14_33760, PA14_48115, PA14_54980, PA14_62000.
