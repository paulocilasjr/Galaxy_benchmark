**19159** individual methylation measurements (rows) are removed from the Zebra Finch dataset when filtering out measurements that do not show >90% or <10% methylation.

The dataset contains 19,698 data rows (rows with methylation measurements). Of those, only 539 have a `MethylationPercentage` either >90% or <10% — these are kept. The remaining 19,159 rows, which fall in the intermediate methylation range (≥10% and ≤90%), are removed by the filter.
