The ratio is **1.703604**.

**Method summary:**

- Parsed the IQ-TREE `.treefile` Newick files from both `scogs_animals.zip` (100 orthogroups) and `scogs_fungi.zip` (249 orthogroups)
- Identified 96 shared single-copy orthogroups present in both kingdoms
- For each orthogroup, computed all pairwise **patristic distances** (sum of branch lengths between leaf pairs on the ML tree) using dendropy
- Took the **mean** of all pairwise distances per orthogroup, per kingdom
- Took the **median** of those per-gene means across the 96 shared orthogroups:
  - Animals median: **0.858044**
  - Fungi median: **1.461767**
- Ratio = 1.461767 / 0.858044 = **1.703604**

The animal trees span 3–4 species (*C. elegans*, *G. gallus*, *M. musculus*, *X. laevis*) and the fungi trees span 3–4 species (*N. crassa*, *S. cerevisiae*, *S. pombe*, *U. maydis*), with varying species counts across orthogroups due to missing single-copy orthologs.
