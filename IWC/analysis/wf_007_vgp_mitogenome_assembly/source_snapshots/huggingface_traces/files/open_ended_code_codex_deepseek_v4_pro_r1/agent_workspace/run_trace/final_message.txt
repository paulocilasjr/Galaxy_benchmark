The mitochondrial genome was assembled and written to [mitogenome.fasta.gz](/workspace/final_answer/mitogenome.fasta.gz).

The final file is a gzip-compressed FASTA with exactly one sequence record, 15,448 bp. The assembly was recovered de novo from a 100,000-read random subset with hifiasm as a circular mitochondrial unitig, then validated by read-back mapping and haploid consensus.
