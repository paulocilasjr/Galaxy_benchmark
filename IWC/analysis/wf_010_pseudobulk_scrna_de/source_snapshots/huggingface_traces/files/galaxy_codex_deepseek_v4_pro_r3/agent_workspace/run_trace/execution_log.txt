Execution log

1. Inspected the assigned Galaxy history and the source AnnData object. The raw counts were in the AnnData `counts` layer, with 4,903 cells, 19,090 genes, and per-cell metadata for `individual`, `disease`, and `cell_type`.

2. Exported the full raw count matrix from the AnnData object in Galaxy as a 10x-style Matrix Market file plus barcodes. The gene list was supplied separately from the AnnData `var` table.

3. Created a Seurat object in Galaxy from the Matrix Market counts, cell barcodes, Ensembl gene IDs, and cell metadata.

4. Added a per-cell `sample` identifier (`<individual>_<cell_type>`), then used Seurat `AggregateExpression` in Galaxy to sum counts by `sample`.

5. Removed the five individual-cell-type combinations with fewer than 10 cells, leaving 34 pseudobulk samples.

6. Filtered genes exactly as specified:
   - N = 34 retained samples
   - M = 556360 (median sample total count)
   - S = ceil(10 + 0.7 * (N - 10)) = 27
   - CPM cutoff = 10 / M * 1e6
   - retained 1,429 genes with CPM >= cutoff in at least 27 samples and summed count >= 1,000.

7. Mapped Ensembl gene IDs back to `gene_symbol` values and produced the final raw pseudobulk count matrix.

8. Split the filtered pseudobulk matrix into one count table per retained sample, created a Galaxy list collection, and supplied a sample sheet with `disease` and `cell_type`.

9. Ran DESeq2 in Galaxy using design formula `~ cell_type + disease`, unshrunken log2 fold changes, and the contrast normal vs COVID-19. Disabled independent filtering and Cook's outlier handling so every gene received finite p-values and adjusted p-values.

10. Recomputed Benjamini-Hochberg adjusted p-values across all 1,429 retained genes and wrote the required files:
    - final_answer/pseudobulk_counts.tsv
    - final_answer/differential_expression.tsv
    - final_answer/method.json
