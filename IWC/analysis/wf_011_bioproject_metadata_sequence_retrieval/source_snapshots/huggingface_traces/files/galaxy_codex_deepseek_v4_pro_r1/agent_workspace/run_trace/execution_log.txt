   - Paired-end runs: 12 forward + 12 reverse compressed FASTQ files
   Raw compressed bytes were saved without decompression, filtering, or recompression.

4. Wrote final deliverables:

   - final_answer/metadata/PRJNA1339024.tsv

   - final_answer/reads/*.fastq.gz
