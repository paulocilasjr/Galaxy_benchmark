**Extended Data Fig. 5 \| Token use by model, outcome and action count.**
**a**, Mean score against median input tokens per run, including cached context, for each model and condition (squares, custom code; circles, Galaxy), by benchmark; IWC shows mean output agreement × 100.
Error bars, 95% cluster-bootstrap intervals (2,000 resamples) for both quantities.
**b**, Input tokens of correct (light) and incorrect (solid) runs by model and condition.
Boxes show the middle 50% and the median, whiskers extend to 1.5 times the interquartile range, and dots are runs.
Numbers give the incorrect / correct ratio within replicate sets that have both outcomes (Fig. 5a pools the models).
**c**, Input tokens against actions for every run with a token count.
Cumulative input grows with the number of actions because each later call carries the retained context, so this association is not a decomposition of cost.
